Aset Kegiatan Pendahuluan (nama file mengikuti Paket_Aset_Pixel_Islami_Referensi).
Dibuat dari kode vektor (js/pend_art.js) lalu diekspor ke PNG transparan, bukan dipotong dari gambar referensi.
Di dalam game, karakter dan ornamen digambar langsung oleh js/pend_art.js (SVG), jadi PNG ini hanya cadangan/pemakaian di tempat lain.
Teks doa Arab dirender sebagai teks Unicode RTL (font Amiri bila online), bukan gambar.
